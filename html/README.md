# Archived: PowerSim v4 static prototype

The files in this directory are the historical PowerSim v4 static browser prototype. They are kept for reference and for legacy schema-compatibility checks (`tests/check_json_contract.py`, `tests/final_test.py`).

They are **not** the PowerSim 1.0 application. `powersim serve` does not serve them, and the wheel and Windows builds do not include them. The PowerSim 1.0 browser application is in `src/powersim/ui/static/`.
